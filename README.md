# موقع ذكريات التخرج ٢٠٢٦

موقع بسيط (HTML/CSS/JS بدون فريموركس) بيعرض كروت كل الخريجين، وبيوديك على صفحة الـ Daftarna بتاعة أي حد تدوس عليه.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الصفحة |
| `style.css` | كل التصميم والألوان والحركة |
| `data.js` | بيانات الخريجين (الاسم / الكلية / اللينك / اسم ملف الصورة) |
| `script.js` | بناء الكروت من `data.js` + البحث الفوري |
| `photos/` | فولدر صور الخريجين (اختياري) |

## إزاي تضيف خريج جديد

افتح `data.js` وزوّد بلوك جديد في نهاية المصفوفة:

```js
{
  name: "اسم الخريج",
  college: "الكلية",
  link: "https://xxxx.daftarna.net/",
  photo: "photos/اسم-الملف.jpg"
},
```

## إزاي تضيف صورة خريج

حط الصورة في فولدر `photos/` بنفس اسم الملف المكتوب في `photo` بتاعته جوه `data.js`.
لو الصورة مش موجودة، الموقع بيسيب الأفاتار الملوّن تلقائيًا — مفيش حاجة هتتكسر.
